# 指示
あなたは国家試験「ITパスポート試験」の専門作問者です。
最新のシラバス（出題基準）に厳密に準拠した4択問題を生成してください。

# 作成条件
1. 分野: 指定された分野（ストラテジ系 / マネジメント系 / テクノロジ系 / 全体ランダム）からバランスよく出題
2. レベル: ITパスポート本試験と同等の難易度（初学者〜実務入門レベル）
3. 形式: 4択（選択肢: A, B, C, D）
4. 解説: 正解の理由だけでなく、すべての誤答選択肢（なぜ不正解か・その用語の意味）を明記すること
5. 最新キーワード（生成AI、DX、ゼロトラスト、アジャイル開発、最新法規など）も積極的に含めること

# 今回の生成範囲
- 分野: {{分野}}（strategy / management / technology のいずれか、または全体ランダム）
- 中分類: {{中分類コード}}（下記コード表から。全体ランダムの場合は「指定なし」）
- 難易度: {{難易度}}（1=基礎: 用語の定義レベル / 2=標準: 本試験の中心レベル / 3=応用: 最新項目・計算・複合知識）
- 問題数: {{問題数}}問

# 中分類コード表
strategy(ストラテジ系): CORP=企業活動, LEGAL=法務, BSTRA=経営戦略マネジメント,
  TSTRA=技術戦略マネジメント, BIZIND=ビジネスインダストリ, SYSSTRA=システム戦略, SYSPLAN=システム企画
management(マネジメント系): SYSDEV=システム開発技術, DEVMGT=ソフトウェア開発管理技術,
  PROJMGT=プロジェクトマネジメント, SVCMGT=サービスマネジメント, AUDIT=システム監査
technology(テクノロジ系): THEORY=基礎理論, ALGO=アルゴリズムとプログラミング,
  HWCOMP=コンピュータ構成要素, SYSCOMP=システム構成要素, SW=ソフトウェア, HW=ハードウェア,
  DESIGN=情報デザイン, MEDIA=情報メディア, DB=データベース, NW=ネットワーク, SEC=セキュリティ

# 品質基準（1問ごとに自己検証すること）
- 正解が一意に定まること。「最も適切なもの」形式では他の選択肢が明確に劣ること
- 誤答選択肢は実在する用語・考え方の説明とし、もっともらしく作ること（明らかに変な選択肢を混ぜない）
- 4つの解説はすべて事実として正しいこと。誤答の解説では、その選択肢が指す用語の正しい意味を必ず述べること
- 問題文は最大300字、選択肢は各最大120字
- 計算問題は解説内に計算過程を示し、検算すること
- 法規問題は現行法に基づくこと（改正内容に言及する場合は施行時期を確認）
- 用語表記はIPAシラバスの用語例に合わせること

## 運用メモ

- 中分類単位・20問前後のバッチで生成する（偏りの検出とレビューのしやすさのため）
- 生成後は `docs/design-spec.md` §9.3 のチェックリストで**必ず人手レビュー**してから
  シードに取り込む（§9.4 の機械検証スクリプトも併用）
- `correctChoice` の分布がA〜Dで偏っていないかはバッチ単位で確認する
  （アプリ側で表示時にシャッフルするため学習上は問題ないが、データ品質の指標にはなる）
- シラバス改訂時は `syllabusVersion` を上げ、影響領域（特にLEGAL / SEC / 生成AI関連）の
  既存問題を優先的に見直す
